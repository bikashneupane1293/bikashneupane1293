# Hi, I'm Bikash Neupane 👋

Building **ProcureNepal** — Construction Industry Operating System for Nepal.

## 🏗️ What I'm Building

A multi-tenant SaaS platform for the Nepalese construction industry and government procurement participants.

**Target users:** Construction Owners · Project Directors · Procurement Officers · Accountants · Store Managers · Site Engineers · Supervisors

**Core capabilities:**
- Tender qualification engine (WPI adjustment · 5-year AACT · Key Activity max-year)
- PPMO-compliant bid capacity calculation
- Multi-party JV agreement builder
- IPC billing with VAT/TDS/retention automation
- Offline-first site diary PWA

## 🛠️ Tech Stack

`NestJS 11` · `Angular 22` · `PostgreSQL 18` · `Redis` · `Prisma` · `Python FastAPI` · `Docker (OrbStack)` · `Ollama` · `Playwright`
